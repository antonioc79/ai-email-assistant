📌 Titolo

AI Email Assistant using GPT

📌 Descrizione

AI-powered web application that classifies emails, summarizes content, and generates professional replies using OpenAI GPT models.

📌 Features
Email classification (work / personal / spam)
Automatic summarization
AI-generated replies
Multi-language support
Interactive web interface (Streamlit)

📌 Tech Stack
Python
Streamlit
OpenAI API

📌 How to run
pip install -r requirements.txt
streamlit run app.py

📌 Example Output
{
  "category": "work",
  "summary": "Meeting request",
  "reply": "Professional response..."
}
